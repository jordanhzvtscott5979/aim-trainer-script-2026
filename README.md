## About Aim Trainer

Aim Trainer is a small browser utility for practicing accuracy and timing directly in a web environment. It gives users a straightforward way to work through target-following exercises, cursor-control drills, and reaction tests without installing a larger desktop application.

Written in vanilla JavaScript and intended for HTML5-style browser use, the project is suited to repeatable practice and quick pre-match warmups. Run a short session before an FPS game or use it whenever you want to improve precision and response speed.
